## Backend dependencies not in this repo

`supabase/migrations` defines only: `mobile_workspace`, `mobile_create_request`, `mobile_save_profile`, `mobile_shipment_details`, and an early `mobile_driver_action` wrapper. `supabase/functions` contains only `create-driver-user`. `supabase/README.md` says the canonical backend lives in the `mabutol-trucking-react` repo.

The client calls these, which are not defined here:
- RPCs: `driver_arrive_at_pickup`, `driver_record_payment`, `driver_submit_pod`, `driver_report_incident_evidence`, `driver_record_position`, `mobile_driver_history`, `mobile_driver_log_fuel`, `mobile_driver_fuel_history`, `mobile_driver_evidence`, `mobile_delivery_evidence_file`, `delivery_conversation`, `delivery_conversation_unread`, `send_delivery_message`, `read_delivery_messages`, `customer_notify_on_the_way`, `confirm_no_show_cancellation`, `customer_submit_suspension_appeal`, `office_review_customer_appeal`
- Edge functions: `mobile-email-login`, `mobile-send-signup-otp`, `mobile-complete-signup`, `delivery-routing`, `calculate-route`
